# Nexora International Web Agency Portfolio

Modern responsive portfolio starter for an international web-development agency.

## Files
- `index.html` — page structure and content
- `style.css` — visual design, responsive layout and animations
- `script.js` — scroll reveals, cursor glow and portfolio tilt interaction

## Before publishing
1. Replace the placeholder agency name `NEXORA`.
2. Replace `hello@example.com`.
3. Replace each `href="#"` demo link with the real live sample URL.
4. Add your real portfolio screenshots/previews if desired.
5. Optimize any large images before adding them.

## GitHub Pages
This project is static HTML/CSS/JS and can be published with GitHub Pages.
